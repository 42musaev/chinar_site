# Чинар — сайт кафе

Статический сайт с меню, корзиной и заказом в WhatsApp: +7 965 700-07-77.

78 позиций меню, поиск, категории, варианты и корзина с сохранением в браузере. Лагман, пельмени и манты без цены; полную сумму подтверждает кафе. Заказ отправляется пользователем в WhatsApp.

Локальный просмотр: `python3 -m http.server 8000`. Откройте http://localhost:8000.

Ресурсы используют абсолютные пути `/`, размещайте сайт в корне домена. Рабочий домен: https://chinaryu.ru/. Для подпапки GitHub Pages нужно адаптировать базовые пути.

`/vpn/` — условия VPN. Серверная панель `/vpn/admin` настраивается отдельно. Код бота, базы данных и пароли не входят в этот репозиторий.
