# Чинар — сайт кафе

Статический сайт с меню, корзиной и отправкой заказа в WhatsApp: +7 965 700-07-77.

- Главная: меню, контакты и реквизиты.
- `/vpn/`: условия VPN-подписки и инструкции.
- Серверная админка `/vpn/admin` настраивается отдельно и не содержит паролей в исходниках.

Для локального просмотра: `python3 -m http.server 8000`.

В репозитории нет кода VPN-бота, ключей доступа и баз данных.
